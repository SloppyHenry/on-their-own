## Wichtige Eigenschaften (alle durch Tests belegt)
- Nichts wird vor dem Commit verteilt; bei Rollback weder gespeichert noch verteilt; `seq` bleibt auch bei vier gleichzeitig schreibenden Threads lückenlos und in Reihenfolge.
- Ein Verbindungsabbruch ändert nichts an der Simulation.
- Fehlerhafte WebSocket-Eingaben schließen die Verbindung mit Code 4400, ausbleibende Antworten auf den Heartbeat mit 4008; der Server läuft weiter.

## Gefundene und behobene Fehler
- Geteilte `Query`/`Path`-Objekte in FastAPI vermischen Parameter (Listenfilter und Orts-/Agenten-Detail); jetzt je Parameter ein eigenes Objekt.
- Der WebSocket schloss bei ungültigem JSON die Verbindung nicht; der Client hätte ewig gewartet.

## Abweichungen und offene Punkte
1. **Gespräch-ID im Dialog fehlt:** `agent.dialogue` entsteht in der Engine, die Gespräche kennt nur der Gesprächsverwalter. Die Zuordnung steht in `agent.conversation_started/_ended`; die Oberfläche kann Beiträge nach Teilnehmerpaar gruppieren.
2. **`agent.moved` je Kachel:** Im Test 299 von 942 Ereignissen in 8 Simulationsstunden (rund 120 Ereignisse je Stunde, ca. 120 KiB). Das ist unkritisch; ob verdichtet wird, entscheidet AP04 an der Darstellung. Gefiltert wird ohnehin über `category`/`type`.
3. **Sichtbarkeit** ist vorerst eine einfache Regel (Weltaktionen öffentlich, Gespräche und Planung nur für Beteiligte, System intern). Mithören durch Dritte bildet sie noch nicht ab; das kommt mit den Wissensgrenzen in AP05/AP08.
4. **`simulation.reset` ist das erste Ereignis der neuen Welt** (`seq` beginnt wieder bei 1). Verbundene Clients bekommen automatisch einen Snapshot, ältere Clients mit zu hoher `seq` ebenfalls.
5. **Kein Zugangsschutz:** der Server bindet an 127.0.0.1; ein optionales Token folgt mit AP10.
6. **Lesende Endpunkte laufen auf dem Schreib-Thread** der Datenbank. Bei dieser Weltgröße unkritisch; bei Bedarf können eigene Leseverbindungen übernehmen (WAL erlaubt das schon).
7. Die erzeugte Datei `generated.ts` ist von der 400-Zeilen-Regel ausgenommen (1092 Zeilen, nicht handgeschrieben).
8. Die Geschwindigkeitsstufen (3 s, 1 s, 0,2 s, 0 pro Tick) sind ein Vorschlag; AP07 macht sie einstellbar.
